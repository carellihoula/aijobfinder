-------
Redesign the AILFJ frontend. The app matches CVs to job offers using an AI
pipeline. The current code is functional and has a decent dark-mode design
system, but several pages are visually broken or inconsistent, and the overall
experience lacks polish and personality. The goal is a cohesive, premium
product feel — think Linear, Vercel, or Raycast.

No new features. No new API calls. No logic changes. Pure visual/UX overhaul.
Keep all existing component names, props, and HTML structure roughly intact
so the app keeps working.

  CURRENT DESIGN SYSTEM (index.css) — DO NOT CHANGE THE TOKEN NAMES
==============================================================================

CSS custom properties (defined in :root / .dark):

  --bg        background canvas
  --card      card surface
  --well      slightly deeper surface (inputs, panels)
  --line      border color base (used with opacity: rgb(var(--line) / 0.10))
  --ink       primary text
  --muted     secondary text
  --subtle    tertiary / placeholder text
  --accent    primary accent (purple: 124,58,237 light / 139,92,246 dark)
  --shadow    box-shadow token

CSS utility classes (keep these working):
  .bd          — 1px border using --line with opacity
  .card        — card surface + border + shadow
  .btn-accent  — gradient purple CTA button with glow
  .btn-ghost   — ghost button with border
  .glass       — frosted glass (navbar)
  .text-grad   — gradient text (ink → muted)
  .app-bg      — page background + radial gradient halo
  .seg-on      — active pill/segment state
  .ring-focus  — accessible focus ring
  .skel        — skeleton shimmer base
  .exp         — animated expand/collapse (max-height transition)
  .clamp-2     — two-line clamp
  .no-scrollbar — hide scrollbar
  .pulse-dot   — pulsing status dot

Font: Geist (sans) + Geist Mono (mono)

Accent color family available as Tailwind colors:
  accent-300 (#c4b5fd) accent-400 (#a78bfa) accent-500 (#8b5cf6)
  accent-600 (#7c3aed) accent-700 (#6d28d9)

Animations defined:
  animate-shimmer      (skeleton shimmer)
  animate-spin-slow    (slow spinner, used in StatusHeader)
  animate-fade-up      (modal entrance / hero)
  animate-pop-in       (spring pop)


==============================================================================
  CRITICAL BUG #1 — LOGIN & REGISTER PAGES DON'T USE THE DESIGN SYSTEM
==============================================================================

LoginPage.tsx and RegisterPage.tsx were never migrated to the CSS var system.
They use raw Tailwind gray/violet classes that clash completely with the rest
of the app (especially in light mode, which has a white/zinc canvas, not
gray-950).

Current broken code pattern:
  className="min-h-screen bg-gray-950 ..."        ← hardcoded dark only
  className="bg-gray-900 border border-gray-800"  ← ignores design system
  className="bg-gray-800 border border-gray-700"  ← inputs look wrong in light
  className="bg-violet-600 hover:bg-violet-500"   ← not using btn-accent

WHAT TO DO:
  - Replace every hardcoded gray-* and violet-* class with design system classes.
  - Use `app-bg` as page background (gives the purple radial glow like UploadPage).
  - Use `card` for the form container.
  - Use `bg-well border border-line/10` for inputs (matching UploadPage inputs).
  - Use `text-ink`, `text-muted`, `text-subtle` for text hierarchy.
  - Use `btn-accent` for the submit button.
  - Keep the BrainCircuit icon + brand name at the top.
  - Add a dark mode class for autofill input colors (WebKit autofill is white).

Make the login page feel like it belongs to the same product as UploadPage.


==============================================================================

--- 2. NAVBAR ---

Improvements:

--- 3. UPLOAD PAGE — HERO SECTION ---
Current: small badge ("Nouvelle analyse"), h1 ("Trouvons votre prochain poste."),

Improvements:

--- 4. MATCH CARDS ---
Current: each card shows:
  - A letter-initial avatar (e.g. "A" for Acme) in a neutral square.
  - Title + company + location
  - Score (e.g. "7.8/10 FORT") colored by tier (emerald/yellow/rose)
  - Tags (contract, mode, seniority) as small pills
  - A score bar (ScoreBar component)
  - Reason text (italic) + short description (2-line clamp)
  - Expand section: full description, missions list, matched/missing skills, action buttons

Improvements:
- Company avatar: instead of a plain neutral square, generate a consistent
  gradient background per company (hash the company name to pick from 6-8
  gradient presets — e.g. purple→blue, emerald→teal, orange→amber, etc.)
  Keep the letter initial, just make it more colorful.
  Example presets (use inline style):
    0: "linear-gradient(135deg, #7c3aed, #4f46e5)"  // violet-indigo
    1: "linear-gradient(135deg, #059669, #0891b2)"  // emerald-cyan
    2: "linear-gradient(135deg, #d97706, #dc2626)"  // amber-red
    3: "linear-gradient(135deg, #db2777, #9333ea)"  // pink-purple
    4: "linear-gradient(135deg, #0284c7, #2563eb)"  // sky-blue
    5: "linear-gradient(135deg, #65a30d, #0d9488)"  // lime-teal
  Use: `GRADIENTS[hashStringToIndex(company, GRADIENTS.length)]`
  where hashStringToIndex sums char codes mod length.

- Score display: the current "7.8/10" with "FORT" below is fine. Make the
  score number bigger or add a small arc gauge (SVG) behind it like StatusHeader
  uses for the spinner.

- Expand animation: already uses max-height trick (.exp class). Keep it.

- "Postuler" button: currently small, inline. Make it slightly more prominent
  (it's the primary action). Consider a full-width button inside the expanded
  section on mobile.

--- 5. ANALYSIS PAGE — PROCESSING STATE ---
Current: StatusHeader shows spinner + step label + % + progress bar.
Below it: MatchSkeletonList (3 skeleton cards).

Improvements:

==============================================================================
  VISUAL REFERENCE / AESTHETIC TARGET
==============================================================================

Aim for: Linear.app + Vercel Dashboard + Raycast

Characteristics:
- Dense but breathable — information-rich without feeling crowded
- Sharp typography hierarchy — clear distinction between h1, body, captions
- Purposeful color — accent purple used sparingly and intentionally
- Dark mode as the premium experience, light mode equally polished
- Subtle gradients and glows — not flat, not garish
- Animations that feel physical and fast — 200-400ms, ease curves (not linear)
- Monospace for numbers, percentages, scores (Geist Mono already set up)

What to avoid:
- Neon overload — accent on every element
- Huge hero images or illustrations
- Slow/bouncy animations
- Any page that uses hardcoded Tailwind gray-* (use CSS vars instead)
